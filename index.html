En preparació
B0

Projecte web

Defineix abans de construir.

Un web no comença escollint un tema. Comença identificant una necessitat real i decidint quin resultat vols oferir.

Avui faràs

  • Escollir un client o context fictici creïble.
  • Definir públic, objectiu i continguts mínims.
  • Escriure criteris d’èxit verificables.

Has de conservar

  • Una fitxa breu del projecte.
  • Un esquema inicial de les pàgines.
  • Una primera llista de tasques de la parella.

Idea clau: cada decisió que prenguis ara t’estalviarà canvis confusos més endavant.

B1

Arquitectura

Entén la cadena abans d’automatitzar-la.

Quan obres un web, el navegador demana una pàgina. El servidor web la processa amb l’aplicació i, si cal, consulta la base de dades.

Navegador→Apache + PHP→WordPress↔MariaDB

Vocabulari essencial

  • Client: el navegador de qui visita.
  • Servidor: qui ofereix el servei.
  • Contenidor: entorn aïllat per executar una aplicació.

Comprova-ho

  • Pots explicar el recorregut d’una petició?
  • Saps per què WordPress necessita MariaDB?
  • Distingeixes una imatge Docker d’un contenidor?
B2

Desplegament

Desplega WordPress sense perdre hores.

La instal·lació es fa a Ubuntu Server 22.04 dins d’IsardVDI. Si treballes des d’una màquina Windows, la faràs servir com a client per connectar-te al servidor.

Abans de començar

  • Tens una VM Ubuntu Server engegada.
  • Pots executar ordres amb sudo.
  • Tens connexió de xarxa i espai de disc.

Seqüència de treball

  1. Instal·la Docker Engine i el connector Compose.
  2. Crea una carpeta de projecte.
  3. Prepara el fitxer compose.yaml.
  4. Inicia els serveis i comprova’n l’estat.
  5. Acaba l’assistent de WordPress al navegador.
docker compose up -d
docker compose ps
docker compose logs -f

Recorda: no copiïs contrasenyes reals a captures ni lliuraments. Farem servir valors d’exemple i variables que puguis substituir.
