Consulta ràpida dels conceptes que aniran apareixent a les AEAs. Les definicions expliquen què és cada element i quin paper té.

Client
Dispositiu o programa que demana un recurs; habitualment, el navegador.
Servidor
Equip o programa que escolta peticions i ofereix un servei a altres equips.
HTTP i HTTPS
Protocols amb què navegador i servidor intercanvien recursos web; HTTPS afegeix xifratge.
Port
Número que identifica un servei dins d’un equip, com 80 per HTTP o 443 per HTTPS.
DNS
Sistema que relaciona noms de domini amb adreces IP.
Apache
Servidor web que rep peticions HTTP i lliura o processa el contingut.
PHP
Llenguatge executat al servidor que WordPress utilitza per generar pàgines dinàmiques.
CMS
Sistema de gestió de continguts que permet crear i administrar un web des d’un panell.
WordPress
CMS basat en PHP que desa contingut i configuració en una base de dades.
MariaDB
Sistema gestor de base de dades on WordPress conserva entrades, pàgines, usuaris i opcions.
Imatge Docker
Plantilla immutable amb l’aplicació i les dependències necessàries per executar-la.
Contenidor
Instància en execució d’una imatge, aïllada però connectable amb altres serveis.
Docker Compose
Fitxer i eina per definir i posar en marxa diversos contenidors de manera reproduïble.
Volum
Espai persistent que conserva dades encara que el contenidor es recreï.
Responsive
Disseny que s’adapta a diferents amplades de pantalla sense perdre llegibilitat ni funcions.
